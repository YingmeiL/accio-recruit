  • 人工搜索商品、供应商与行业信息，信息分散，反复整理。

  • 围绕目标组织多步任务，生成候选清单、比较表与下一步建议。
  • 研究过程、数据、工具调用与结果，沉淀为可复用的工作流。

02 · PRODUCT

从“采购助手”，到执行型工作平台

Accio 不止输出文字。它能读取资料、调用工具、运行任务、操作浏览器，在权限边界内持续完成工作。内置数百项实用技能，老板不懂技术，也能把生意跑起来——一人跨国公司，来了。

场景 A

全球选品与供应商研究

从一个想法出发研究市场、锁定机会；把报价单、发票整理成可比较的数据；筛选、比较供应商，给出谈判建议。我们正在把搜索引擎，升级成采购决策引擎。

场景 B

店铺创建与经营自动化

用一句自然语言创建 Shopify 店铺，产品、内容、邮件一起安排好；报告、库存检查、数据更新按计划执行；国际站生意助手以插件接入同一工作流，少切几个窗口。

场景 C

从资料到工具与结果

读取本地文件提取报价与报告；现场造一个计算器或分析工具；浏览器搜网页、填表单、截图推进多步流程；用技能、MCP 和第三方连接器扩展能力边界。

普通聊天工具

  • 主要提供文字回答，搜索、整理、操作还得你自己来。
  • 能力边界固定，工作流靠手动串联。
  • 结果通常停留在单次会话。
→

Accio Work 的产品方向

  • 面向目标交付：研究信息、处理文件、创建工具、操作浏览器。
  • Agent、技能、MCP、团队协作与自动化，组合出可复用工作流。
  • 支持定时任务、持续更新、主动跟进和多 Agent 协作。
03 · TECH STACK

在真实复杂度里，做 Agent 与大模型

这里有一套“研究前沿 + 产品验证 + 商业闭环”的技术环境：从模型训练到系统执行，从离线评测到线上反馈，一条链路看完。

Agent 与长程任务

复杂规划、多轮搜索、多工具协作、持续记忆，以及可能持续数天的异步谈判与供应商沟通。

搜索与深度研究

跨语言、跨平台检索供应商资质、产品参数和行业法规，把多步推理与全网开放信息结合起来。

多模态与多语言

理解文字、图片、视频、3D 与复杂结构化图片；图文混合检索，商品 / 供应商 / 制造商多意图搜索。

Agentic Post-training

Agentic SFT、CPT、Reasoning RL、Agentic RL、RLHF / RLAIF，提升 DeepResearch、Coding、Tool Use 与长链路推理。

强化学习与工具调用

在异构 API 环境中做任务编排、纠错和执行；研究环境设计、奖励塑形与信用分配。

AI Infra

分布式训练、全球推理服务、Agentic RL 环境模拟器和数据流水线；吞吐、容错、缓存、量化与成本优化。

安全与对齐

应对 Prompt Injection、越权调用、目标偏移、数据外泄和未授权行动——Agent 时代特有的风险。
